## Description
* **This project teaches you how to get started with the command-line interface (Terminal) and briefly introduces you to some of the most important commands:**
- pwd: To find your current location ("your path")
- ls: To display the contents of the files you are currently in
- cd: To navigate between folders
- mkdir: To create a folder
- clear: To clear the terminal screen contents
- touch: To create a file
- echo: To write to the file without opening it
- cat: To display the file contents on the terminal screen
- cp: To copy files or directories
- mv: To move or rename
- rm: To remove

* **Also, adapting to the process of creating Git repositories and pushing to them—while writing clear commit messages is key. Here is a summary of the commands used:**
- git init: To initialize a new, empty Git repository locally
- status: To view the status of files that have been added or prepared for upload.
- add: To register the files to be uploaded
- commit: To write a cover letter for the uploaded files and confirm the uploaded files.
- log: To display the log line for the git, information about the person who performed the upload (such as name, email, etc., if recorded), the commit timestamp, and the commit message.
- remote: To manage and connect your local repository to a remote server like GitHub
- push: To upload the information and files stored in Git to the repository on the website.
- ssh-keygen: SSH key how to link it and use it.

* You will also learn how to create a README.md file using Markdown.

## Why Git Makes Development Easier
It offers a seamless experience for adding, uploading, pulling, and modifying files, with the ability to attach an explanatory message to almost every operation. Furthermore, it allows you to review upload history and view previous changes—along with many other features that make working with it smooth and easy.
